## Pasos a Implementar

### 1. Configurar Sanctum para SPA Authentication
- Publicar configuración de Sanctum (ya existe)
- Asegurar que `config/sanctum.php` tenga guard 'web' configurado
- Verificar que el modelo User usa el trait `HasFactory`

### 2. Configurar rutas API de autenticación
- Crear rutas API para login, logout, register, password-reset
- Middleware `stateful` para cookies SPA

### 3. Configurar autenticación con tokens (Sanctum)
- Verificar que el modelo User implementa `MustVerifyEmail` si es necesario
- Agregar método `createToken` para API tokens

### 4. Configuración de Laravel Boost (opcional)
- Verificar que Boost funcione con Fortify/Sanctum

### 5. Crear Tests de autenticación
Crear archivo `tests/Feature/AuthenticationTest.php` con:
- `test_users_can_register`: Verificar registro de usuarios
- `test_users_can_login`: Verificar login con credenciales válidas
- `test_users_cannot_login_with_invalid_credentials`: Verificar login fallido
- `test_users_can_logout`: Verificar logout
- `test_authenticated_users_can_access_protected_routes`: Verificar acceso con token
- `test_unauthenticated_users_cannot_access_protected_routes`: Verificar acceso denegado
- `test_users_can_create_personal_access_token`: Verificar creación de token API

### 6. Ejecutar tests y verificar
- Ejecutar `php artisan test --filter=AuthenticationTest`
- Verificar que todos los tests pasen
