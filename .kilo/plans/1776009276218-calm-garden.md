# Plan: Factories y Seeders con Roles y Permisos por Defecto

## Objetivo
Crear factories y seeders para usuarios con roles predefinidos (Super-Admin, Manager, Player).

---

## Estructura Actual
- **Autenticación**: Sanctum + Fortify
- **Roles/Permisos**: Spatie laravel-permission v7.3.0
- **Usuario**: `fullname`, `username`, `email`, `password` (usa trait `HasRoles`)

---

## Plan de Implementación

### 1. Modificar `UserFactory`
- Agregar estado `superAdmin()` que crea usuario con rol Super-Admin
- Agregar estado `admin()` que crea usuario con rol Manager
- Agregar estado `player()` que crea usuario con rol Player

### 2. Crear `RoleSeeder`
- Crear permisos para:
  - **Gestión de aplicación**: `manage-users`, `manage-roles`, `manage-settings`
  - **Predicciones**: `create-predictions`, `edit-predictions`, `view-predictions`
  - **Resultados**: `view-results`
  - **Perfil**: `edit-profile`, `view-profile`
  - **Clasificación**: `view-leaderboard`
- Crear roles:
  - **Super-Admin**: Todos los permisos
  - **Manager**: Permisos de gestión + viewer
  - **Player**: Predicciones, perfil, resultados, leaderboard

### 3. Crear `UserSeeder`
- Crear usuario **superadmin** (superadmin@quiniela.com / password)
- Crear usuario **administrador** (admin@quiniela.com / password)
- Los nuevos registros tendrán rol Player por defecto

### 4. Actualizar `DatabaseSeeder`
- Llamar a `RoleSeeder` primero
- Llamar a `UserSeeder`
- Comentar o eliminar creación de usuario de prueba genérico

---

## Orden de Ejecución

```
1. php artisan make:seeder RoleSeeder
2. php artisan make:seeder UserSeeder
3. Editar database/factories/UserFactory.php
4. Editar database/seeders/RoleSeeder.php
5. Editar database/seeders/UserSeeder.php
6. Editar database/seeders/DatabaseSeeder.php
7. php artisan db:seed (para probar)
```

---

## Notas
- El usuario por defecto tiene password: `password`
- Los roles se asignan usando el método `assignRole()` de Spatie
- El seeder debe verificar si los roles ya existen para evitar duplicados
